# ElasticT3 单轴拉伸算例（理论解验证）

> 算例文件：`ElasticT3.dat`；参考 GiD 模板：`ElasticT3.gid/ElasticT3.bas`。
> 用途：为弹性力学三角形单元（CST，平面应力）提供有解析解的回归基准。

## 1. 算例概述

平面应力常应变三角形单元（CST）单轴均匀拉伸。CST 只能表达常应变/常应力，对**均匀应变场**可给出机器精度精确解，故选单向均匀拉伸作为验证算例：位移驱动（强制位移边界）+ 零体力，避免应力梯度。

## 2. 网格

矩形区域 [0,1]×[0,1]，3×3 节点（共 9 节点），划分为 8 个三角形单元。坐标与连接详见 `ElasticT3.dat` 的 `coord`/`ElT3` 段。

```
7(0,1)  8(0.5,1)  9(1,1)
4(0,0.5) 5(0.5,0.5) 6(1,0.5)   ← 节点5为唯一自由求解节点
1(0,0)  2(0.5,0)  3(1,0)
```

## 3. 材料（`ElT3` 段，参数顺序对应 `DomainData._mateConstitutive["ElT3"]`）

| 参数 | 值 | 含义 |
| --- | --- | --- |
| E | 1.0e6 | 弹性模量 |
| nu | 0.3 | 泊松比 |
| t | 1.0 | 厚度 |
| fx | 0.0 | 体力密度 x（面力无 dat 段，载荷只能走体力或强制位移） |
| fy | 0.0 | 体力密度 y |

## 4. 边界条件（`ubfElastic2DDisp` 段 = 第一类强制位移）

理论位移场取均匀应变 ε₀ = 1.0e-3：

- u(x,y) = ε₀·x
- v(x,y) = −ν·ε₀·y

外圈 8 个节点（1,2,3,4,6,7,8,9）强制为各自的理论位移；**中心节点 5 不加约束，由求解器求解**，作为关键校验点。

> `id` 段（`readID`）当前为空实现，约束值实际由 `ubf` 段经 `setFirstBoundry` 施加。

## 5. 理论解（平面应力单向拉伸）

- 应变：εx = ε₀ = 1e-3，εy = −ν·ε₀ = −3e-4，γxy = 0
- 应力：

  - σx = E/(1−ν²)·(εx + ν·εy) = E/(1−ν²)·ε₀·(1−ν²) = **E·ε₀ = 1000**
  - σy = E/(1−ν²)·(ν·εx + εy) = E/(1−ν²)·(ν·ε₀ − ν·ε₀) = **0**
  - τxy = **0**

- 位移：u = ε₀·x，v = −ν·ε₀·y

## 6. 验证结果（对齐基准）

运行 `ElasticT3.exe ElasticT3 .` 后，`ElasticT3.post.res` 中全部 9 节点位移 7 位有效数字匹配理论值。关键自由求解节点 5 = **(5.0000000e-04, −1.5000000e-04)**，与理论 (ε₀·0.5, −ν·ε₀·0.5) 完全一致。

| 节点 | 理论 (u,v) | 实测 (u,v) |
| --- | --- | --- |
| 1 (0,0) | (0, 0) | (0, 0) ✓ |
| 2 (0.5,0) | (5e-4, 0) | (5.000e-4, 0) ✓ |
| 3 (1,0) | (1e-3, 0) | (1.000e-3, 0) ✓ |
| 4 (0,0.5) | (0, −1.5e-4) | (0, −1.500e-4) ✓ |
| **5 (0.5,0.5)** | **(5e-4, −1.5e-4)** | **(5.000e-4, −1.500e-4)** ✓ |
| 6 (1,0.5) | (1e-3, −1.5e-4) | (1.000e-3, −1.500e-4) ✓ |
| 7 (0,1) | (0, −3e-4) | (0, −3.000e-4) ✓ |
| 8 (0.5,1) | (5e-4, −3e-4) | (5.000e-4, −3.000e-4) ✓ |
| 9 (1,1) | (1e-3, −3e-4) | (1.000e-3, −3.000e-4) ✓ |

应力（σx=1000, σy=0, τxy=0）已接入输出并验证：`main.cpp` 注册 `stress`（`Vector3`，`OnGaussPoints`，分量 Sxx/Syy/Sxy），核心库 `post` 经 `ResLocation::OnGaussPoints` 分支按单元子程序输出 `GaussPoints` 定义 + `Result ... Vector:3 OnGaussPoints` + 逐单元值。实测 8 单元：

| 单元 | σx | σy | τxy |
| --- | --- | --- | --- |
| 1–7 | 1.0000000e+03 | 0.0000000e+00 | 0.0000000e+00 |
| 8 | 1.0000000e+03 | −1.14e-13 | 5.68e-14 |

σx 精确等于 E·ε₀=1000；σy、τxy 为机器精度 0（第 8 单元的 1e-13 量级残差为浮点舍入）。

## 7. 运行方法

```bash
cd FEMproject/sample/ElT3
<构建输出目录>/ElasticT3.exe ElasticT3 .
```

读 `ElasticT3.dat`（路径 `<path>/<project>.dat`，即 `./ElasticT3.dat`），输出 `ElasticT3.post.msh` 与 `ElasticT3.post.res`。

## 8. 加密网格变体（ElasticT3_4x4.dat）

同一单轴拉伸理论解的加密版本，单元仍为 CST 三角形，用于多点回归验证：

- **网格**：4×4 节点（16 节点）/ 18 个三角形，矩形 [0,1]²，间距 1/3。
- **自由求解节点**：内部 4 个（6,7,10,11）；外圈 12 个强制理论位移。
- **材料与理论解**：与 3×3 算例完全相同（E=1e6, ν=0.3, ε₀=1e-3；σx=1000, σy=τxy=0）。

验证结果：

- 4 个内部节点位移全部 7 位有效数字匹配理论（如节点 11 = (6.6666667e-04, −2.0000000e-04)）。
- 18 个单元 σx = 1.0000000e+03（精确）；σy、τxy 残差 ≤6.4e-11（机器精度；因 1/3 坐标的浮点表示，略大于 3×3 的 ~1e-13 量级）。

运行：

```bash
cd FEMproject/sample/ElT3
<构建输出目录>/ElasticT3.exe ElasticT3_4x4 .
```

读 `ElasticT3_4x4.dat`，输出 `ElasticT3_4x4.post.msh` 与 `ElasticT3_4x4.post.res`。

> 说明：CST 对均匀应变场解析精确，加密网格不改变计算精度，仅将"独立求解验证点"由 1 个（3×3 的节点 5）增至 4 个，使回归基线更稳健。
