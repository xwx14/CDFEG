# 前后处理配置上提（_resItems → DomainData::PrePostConfig）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `_resItems` 从 `Processor` 基类上提到 `DomainData::PrePostConfig`，拆 `_nodeResItems`/`_eleResItems` 两桶，多 processor 共享，GiD analysis 名可配置。

**Architecture:** 新建 `PrePostConfig` 配置类以值成员组合到 `DomainData`；`Processor` 移除 `_resItems`/`_bNeedTime`；`gidPrePost::post`/`vtkPost::post` 改为按容器分流；6 个示例 main 按项 `_loc` 分流注册；pyTool 模板同步。前序 `多processor统一后处理` spec 已实施，本次为其下一步延续。

**Tech Stack:** C++14 / CMake（mingw64）/ Eigen 3.4 / Python 3 + Jinja2（pyTool）/ e2e 回归框架（test/）
