**⚠️ 术语变更（2026-07-29）**：本文档中的 `gidName` 已重命名为 `matName`（pyTool `DataEleSub` 类）。下文出现的 `gidName` 均指现今的 `matName`，原文保留未改。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将材料参数 schema 从 `ElementBase._paramNames` 上移到 `DomainData._mateConstitutive`，单元仅持 `_mateTypeName` 引用本构类型，`readMate` 用本构类型名查表——使 Hel2D 热固耦合无需手改单元 `_name` 即可共享同一材料段。

**Architecture:** P0 阶段**保留** `ElementBase._paramNames` 作 `readMate` 回退兼容（本构表优先、找不到则回退单元 `_paramNames`），旧示例（truss/El2D/ElT3/DEl2D）零改动仍可运行；新增 `DomainData._mateConstitutive` + `addMateType`、`ElementBase._mateTypeName`、`readMate` 本构表路径；pyTool 新增 `DataProject.mateTypes` + `DataEleSub.mateTypeName` 数据模型与模板渲染；Hel2D 改用显式本构类型 `HelQ4g`。P1（迁移其余 sample + 删除 `_paramNames` + readMate 回退）见文末"后续工作"，另行执行。

**Tech Stack:** C++14（核心库 DLL，Eigen 3.4，MinGW Makefiles / MSVC）、Python 3 + Jinja2（pyTool）、pytest。

- Produces: `readMate` 行为变更——材料段头 `name` 先查 `_mateConstitutive`；未命中则遍历单元找 `mat_<单元 _name> == name` 用其 `_paramNames`（旧路径，兼容旧示例）。

- [ ] **Step 1: 用新实现替换 `readMate` 函数体**

将 `gidPrePost.cpp` 中 `int GidPrePost::readMate(const std::map<std::string, std::string>& params)` 整个函数体替换为：

```cpp
int GidPrePost::readMate(const std::map<std::string, std::string>& params)
{
	std::string name = params.at("name");
	// 优先走本构类型表（新机制）：材料段头 name 即本构类型名
	auto itType = _femData->_mateConstitutive.find(name);
	const std::vector<std::string>* pmateparams = nullptr;
	if (itType != _femData->_mateConstitutive.end())
	{
		pmateparams = &itType->second;
	}
	else
	{
		// 回退（旧机制）：按 mat_<单元 _name> 找单元，用其 _paramNames
		ElementBase* curEle = nullptr;
		for (PhyFieldData* f : _femData->_phyDatas)
		{
			for (ElementBase* e : f->_eleSubs)
			{
				if ("mat_" + e->_name == name) { curEle = e; break; }
			}
			if (curEle) break;
		}
		if (!curEle) return -1;
		pmateparams = &curEle->_paramNames;
	}
	const std::vector<std::string>& mateparams = *pmateparams;
	const std::string& line = _datReader.getCurrentLine();
	int i = 0;
	while (_datReader.readNextLine()) {
		if (line[0] == '*') {
			_datReader.preLine();
			break;
		}
		std::vector<double> vals = TextReader::splitDoubles(line, " ,");
		int len1 = vals.size();
		if (len1 > (int)mateparams.size())len1 = mateparams.size();
		std::map<std::string, double> paramMap;
		for (int j = 0; j < len1; ++j) {
			paramMap[mateparams[j]] = vals[j];
		}
		_femData->addMate(paramMap, name+"_" + std::to_string(++i));
	}
	return 0;
}
```

```python
    @staticmethod
    def _applyMateTypeCompat(project):
        """未声明 mateTypeName 的单元：默认取单元名，并用其 paramNames 注册同名本构类型。
        使旧 test 脚本（仅设 paramNames）零改动即可走新本构表机制。"""
        existing = {mt['name'] for mt in project.mateTypes}
        for field in project.fields:
            for ele in field.eleSubs:
                if not ele.mateTypeName:
                    ele.mateTypeName = ele.name
                    if ele.paramNames and ele.name not in existing:
                        project.addMateType(ele.name, ele.paramNames, ele.paramValues)
                        existing.add(ele.name)
```
