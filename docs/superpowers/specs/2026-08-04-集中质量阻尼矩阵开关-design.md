# 集中质量/阻尼矩阵开关（bLumpMass / bLumpDamp）

> 状态：已批准（2026-08-04）
> 范围：pyTool 代码生成器
> 关联：[pyTool CLAUDE.md](../../../pyTool/CLAUDE.md)、[pyTool能力边界.md](../../../.claude/rules/pyTool能力边界.md)

## 1. 背景与动机

`elesub.cpp.j2` 当前在 `IsoEleBase` 分支构造函数中，对单元结果矩阵做固定规模 resize：

```cpp
_result.emass.resize(_nVar);           // 质量：一维（集中/对角）
_result.eload.resize(_nVar);           // 载荷向量：一维
_result.estif.resize(_nVar * _nVar);   // 刚度：满矩阵
_result.edamp.resize(_nVar);           // 阻尼：一维（集中/对角）
```

其中 `_nVar = nNodes * nDisp`（单元总自由度数）。

现状下 `emass`/`edamp` 恒为**集中（lumped，对角）**形式（一维 `_nVar`），无法表达**一致（consistent，满）质量/阻尼矩阵**（`_nVar * _nVar`）。一致矩阵在显式动力学、某些特征值问题中有需求。

需要为 `DataEleSub` 增加两个开关，让生成器能按需产出两种规模的矩阵。

## 2. 目标

- 新增 `bLumpMass`、`bLumpDamp` 两个布尔字段，默认 `True`（集中，与现状一致）。
- 模板依据开关控制 `emass`/`edamp` 的 resize 规模：
  - `True`（集中）→ `resize(_nVar)`
  - `False`（一致）→ `resize(_nVar * _nVar)`
- 默认值保证现有示例（DEl2D 等）重生成结果**完全向后兼容**。
- 序列化字段，保证 GUI 存档 `.cdfeg.json` 完整可恢复。

## 3. 设计

### 3.1 `pyTool/DataEleSub.py`

**(a) `__init__`** — 在 `calMatrix`（第 56 行）附近新增：

```python
# 是否为集中质量矩阵（True=集中/对角 resize(_nVar)，False=一致/满 resize(_nVar*_nVar)）
self.bLumpMass=True
# 是否为集中阻尼矩阵（True=集中/对角，False=一致/满）
self.bLumpDamp=True
```

**(b) `toDict()`** — `'calMatrix'` 条目后追加：

```python
'bLumpMass': self.bLumpMass,
'bLumpDamp': self.bLumpDamp,
```

**(c) `fromDict()`** — `calMatrix` 恢复后追加（默认 `True` 兼容旧存档）：

```python
ele.bLumpMass = data.get('bLumpMass', True)
ele.bLumpDamp = data.get('bLumpDamp', True)
```

### 3.2 `pyTool/template/elesub.cpp.j2`（IsoEleBase 分支）

替换原第 33、36 行的固定 resize：

```cpp
    caculateShapeCoef({{ ele.dim }});
{% if ele.bLumpMass %}
    _result.emass.resize(_nVar);
{% else %}
    _result.emass.resize(_nVar * _nVar);
{% endif %}
    _result.eload.resize(_nVar);
    _result.estif.resize(_nVar * _nVar);
{% if ele.bLumpDamp %}
    _result.edamp.resize(_nVar);
{% else %}
    _result.edamp.resize(_nVar * _nVar);
{% endif %}
```

## 4. 不改动（YAGNI）

| 项 | 理由 |
| --- | --- |
| `estif`（刚度） | 恒为满矩阵，无"集中刚度"物理概念，不加开关 |
| `eload`（载荷向量） | 恒为 `_nVar`，本就是一维向量 |
| `DataEleSubG` | 通过 `super().toDict()` 与 `__dict__.update(base_ele.__dict__)` 自动继承字段与序列化，无需改动 |
| 非 `IsoEleBase` 分支（`EleSubBase`） | 该分支构造函数无此 resize 段，不受影响 |
| GUI（`project_model.py` 等） | 本次未要求可视化编辑开关；属后续工作 |

## 5. 兼容性

- **默认 `True`**：现有所有示例重生成结果与当前完全一致（`emass`/`edamp` 仍为 `_nVar`）。
- **旧存档**：`fromDict` 的 `data.get(..., True)` 保证缺字段时回退默认值，旧 `.cdfeg.json` 无需迁移。
- **核心库运行时**：本改动仅影响生成代码中矩阵的 resize 规模（内存分配）；实际如何填充与使用由手填的 `run`/`uEle`/`uPhy` 决定。当前核心库动力学（Newmark 有效矩阵 `K+a0M+a1C`）按对角使用 `emass`/`edamp`，与默认 `True` 一致；若用户将某单元设为 `False`（一致），需自行在手填代码中按满矩阵处理。

## 6. 验证

- **生成对比**：对 `testDEL2D.py`（默认 `True`）执行生成，diff 确认产物 C++ 与改动前完全一致（向后兼容）。
- **开关生效**：构造一个临时单元设 `bLumpMass=False`、`bLumpDamp=False`，渲染模板，确认 `emass`/`edamp` resize 为 `_nVar*_nVar`。
- **序列化往返**：`toDict` → `fromDict` 往返，确认两字段值保留；缺字段的旧 dict 往返后为 `True`。

## 7. 范围外

- 一致质量/阻尼矩阵的**实际填充逻辑**（高斯积分 `∫ρNᵀN dV`）——属手填 `run` 代码，不在生成器职责内。
- GUI 可视化编辑这两个开关。
