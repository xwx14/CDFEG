# 材料库数据库设计方案

## 一、概述

本文档描述基于 SQLite 的材料库数据库设计方案，用于存储和管理有限元分析中的材料数据、本构模型及其参数。

### 设计原则

- 使用业务主键（name）而非自增 ID，提高可读性和数据可移植性
- 支持材料与多个本构模型的关联（多对多关系）
- 同一材料的同名参数在不同本构中共享同一值
- 完整的外键约束保证数据一致性

### 技术栈

- 数据库：SQLite 3.x
- 主键策略：TEXT 类型业务主键
- 外键：启用并配置级联操作

## 二、数据库表结构

### 2.1 PhysicsType（物理类型表）

存储物理场类型分类。

| 列名    | 数据类型 | 约束        | 说明                                     |
| ------- | -------- | ----------- | ---------------------------------------- |
| name    | TEXT     | PRIMARY KEY | 物理类型唯一标识（如 "solid_mechanics"） |
| ch_name | TEXT     | NOT NULL    | 中文名称（如 "固体力学"）                |

**DDL**

```sql
CREATE TABLE PhysicsType (
    name TEXT PRIMARY KEY,
    ch_name TEXT NOT NULL
);
```

**示例数据**

```sql
INSERT INTO PhysicsType VALUES ('solid_mechanics', '固体力学');
INSERT INTO PhysicsType VALUES ('fluid_mechanics', '流体力学');
INSERT INTO PhysicsType VALUES ('thermal', '热学');
INSERT INTO PhysicsType VALUES ('electromagnetic', '电磁学');
```

---

### 2.2 MateType（本构模型表）

存储所有可用的材料本构模型。

| 列名      | 数据类型 | 约束         | 说明                                    |
| --------- | -------- | ------------ | --------------------------------------- |
| name      | TEXT     | PRIMARY KEY  | 本构模型唯一标识（如 "linear_elastic"） |
| ch_name   | TEXT     | NOT NULL     | 中文名称（如 "线弹性"）                 |
| phys_name | TEXT     | NOT NULL, FK | 所属物理类型，引用 PhysicsType.name     |

**DDL**

```sql
CREATE TABLE MateType (
    name TEXT PRIMARY KEY,
    ch_name TEXT NOT NULL,
    phys_name TEXT NOT NULL,
    FOREIGN KEY (phys_name) REFERENCES PhysicsType(name)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);

CREATE INDEX idx_matetype_phys ON MateType(phys_name);
```

**示例数据**

```sql
INSERT INTO MateType VALUES ('linear_elastic', '线弹性', 'solid_mechanics');
INSERT INTO MateType VALUES ('plasticity', '塑性', 'solid_mechanics');
INSERT INTO MateType VALUES ('mooney_rivlin', 'Mooney-Rivlin', 'solid_mechanics');
INSERT INTO MateType VALUES ('neo_hookean', 'Neo-Hookean', 'solid_mechanics');
```

---

### 2.3 MateParam（材料参数表）

存储所有材料参数的元数据定义。

| 列名        | 数据类型 | 约束        | 说明                                      |
| ----------- | -------- | ----------- | ----------------------------------------- |
| name        | TEXT     | PRIMARY KEY | 参数唯一标识（如 "youngs_modulus"）       |
| ch_name     | TEXT     | NOT NULL    | 中文名称（如 "弹性模量"）                 |
| unit        | TEXT     | NULL        | 单位（如 "Pa", "kg/m³"）                  |
| data_type   | TEXT     | NOT NULL    | 数据类型（scalar/vector/tensor/curve）    |
| value_range | TEXT     | NULL        | 有效范围描述（如 ">0", "0~1", "[-1, 1]"） |

**DDL**

```sql
CREATE TABLE MateParam (
    name TEXT PRIMARY KEY,
    ch_name TEXT NOT NULL,
    unit TEXT,
    data_type TEXT NOT NULL CHECK(data_type IN ('scalar', 'vector', 'tensor', 'curve')),
    value_range TEXT
);
```

**示例数据**

```sql
INSERT INTO MateParam VALUES ('youngs_modulus', '弹性模量', 'Pa', 'scalar', '>0');
INSERT INTO MateParam VALUES ('poisson_ratio', '泊松比', '', 'scalar', '0~0.5');
INSERT INTO MateParam VALUES ('density', '密度', 'kg/m³', 'scalar', '>0');
INSERT INTO MateParam VALUES ('yield_stress', '屈服应力', 'Pa', 'scalar', '>0');
INSERT INTO MateParam VALUES ('c10', 'C10系数', 'Pa', 'scalar', NULL);
INSERT INTO MateParam VALUES ('c01', 'C01系数', 'Pa', 'scalar', NULL);
```

### 2.4 MateTypeParam（本构模型-参数关联表）

定义每个本构模型需要哪些参数及其属性。

| 列名            | 数据类型 | 约束            | 说明                             |
| --------------- | -------- | --------------- | -------------------------------- |
| mat_type_name   | TEXT     | PRIMARY KEY, FK | 本构模型名称，引用 MateType.name |
| mate_param_name | TEXT     | PRIMARY KEY, FK | 参数名称，引用 MateParam.name    |
| is_required     | INTEGER  | NOT NULL        | 是否必需参数（1=必需，0=可选）   |
| default_value   | REAL     | NULL            | 默认值（可选）                   |

**DDL**

```sql
CREATE TABLE MateTypeParam (
    mat_type_name TEXT NOT NULL,
    mate_param_name TEXT NOT NULL,
    is_required INTEGER NOT NULL CHECK(is_required IN (0, 1)),
    default_value REAL,
    PRIMARY KEY (mat_type_name, mate_param_name),
    FOREIGN KEY (mat_type_name) REFERENCES MateType(name)
        ON UPDATE CASCADE
        ON DELETE CASCADE,
    FOREIGN KEY (mate_param_name) REFERENCES MateParam(name)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);

CREATE INDEX idx_matetypeparam_param ON MateTypeParam(mate_param_name);
```

**示例数据**

```sql
-- 线弹性本构
INSERT INTO MateTypeParam VALUES ('linear_elastic', 'youngs_modulus', 1, NULL);
INSERT INTO MateTypeParam VALUES ('linear_elastic', 'poisson_ratio', 1, NULL);
INSERT INTO MateTypeParam VALUES ('linear_elastic', 'density', 0, NULL);

-- 塑性本构
INSERT INTO MateTypeParam VALUES ('plasticity', 'youngs_modulus', 1, NULL);
INSERT INTO MateTypeParam VALUES ('plasticity', 'poisson_ratio', 1, NULL);
INSERT INTO MateTypeParam VALUES ('plasticity', 'yield_stress', 1, NULL);
INSERT INTO MateTypeParam VALUES ('plasticity', 'density', 0, NULL);

-- Mooney-Rivlin本构
INSERT INTO MateTypeParam VALUES ('mooney_rivlin', 'c10', 1, NULL);
INSERT INTO MateTypeParam VALUES ('mooney_rivlin', 'c01', 1, NULL);
INSERT INTO MateTypeParam VALUES ('mooney_rivlin', 'density', 0, NULL);
```

### 2.5 Mate（材料表）

存储具体的材料实例。

| 列名       | 数据类型 | 约束        | 说明                      |
| ---------- | -------- | ----------- | ------------------------- |
| name       | TEXT     | PRIMARY KEY | 材料唯一标识（如 "Q235"） |
| ch_name    | TEXT     | NOT NULL    | 中文名称（如 "Q235钢"）   |
| created_at | TEXT     | NOT NULL    | 创建时间（ISO8601 格式）  |
| updated_at | TEXT     | NOT NULL    | 更新时间（ISO8601 格式）  |

**DDL**

```sql
CREATE TABLE Mate (
    name TEXT PRIMARY KEY,
    ch_name TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

-- 自动更新 updated_at 的触发器
CREATE TRIGGER update_mate_timestamp 
AFTER UPDATE ON Mate
FOR EACH ROW
BEGIN
    UPDATE Mate SET updated_at = datetime('now') WHERE name = NEW.name;
END;
```

**示例数据**

```sql
INSERT INTO Mate (name, ch_name) VALUES ('Q235', 'Q235钢');
INSERT INTO Mate (name, ch_name) VALUES ('aluminum_6061', '6061铝合金');
INSERT INTO Mate (name, ch_name) VALUES ('concrete_c30', 'C30混凝土');
```

### 2.6 MateMateType（材料-本构模型关联表）

定义每个材料使用哪些本构模型（多对多关系）。

| 列名          | 数据类型 | 约束            | 说明                             |
| ------------- | -------- | --------------- | -------------------------------- |
| mat_name      | TEXT     | PRIMARY KEY, FK | 材料名称，引用 Mate.name         |
| mat_type_name | TEXT     | PRIMARY KEY, FK | 本构模型名称，引用 MateType.name |
| is_active     | INTEGER  | NOT NULL        | 是否启用该本构（1=启用，0=禁用） |

**DDL**

```sql
CREATE TABLE MateMateType (
    mat_name TEXT NOT NULL,
    mat_type_name TEXT NOT NULL,
    is_active INTEGER NOT NULL CHECK(is_active IN (0, 1)) DEFAULT 1,
    PRIMARY KEY (mat_name, mat_type_name),
    FOREIGN KEY (mat_name) REFERENCES Mate(name)
        ON UPDATE CASCADE
        ON DELETE CASCADE,
    FOREIGN KEY (mat_type_name) REFERENCES MateType(name)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);

CREATE INDEX idx_matemate_type ON MateMateType(mat_type_name);
```

**示例数据**

```sql
INSERT INTO MateMateType VALUES ('Q235', 'linear_elastic', 1);
INSERT INTO MateMateType VALUES ('Q235', 'plasticity', 1);
INSERT INTO MateMateType VALUES ('aluminum_6061', 'linear_elastic', 1);
```

### 2.7 MatValue（材料参数值表）

存储每个材料的具体参数值。同一材料的同名参数在不同本构中共享。

| 列名            | 数据类型 | 约束            | 说明                          |
| --------------- | -------- | --------------- | ----------------------------- |
| mat_name        | TEXT     | PRIMARY KEY, FK | 材料名称，引用 Mate.name      |
| mate_param_name | TEXT     | PRIMARY KEY, FK | 参数名称，引用 MateParam.name |
| value           | REAL     | NOT NULL        | 参数值                        |

**DDL**

```sql
CREATE TABLE MatValue (
    mat_name TEXT NOT NULL,
    mate_param_name TEXT NOT NULL,
    value REAL NOT NULL,
    PRIMARY KEY (mat_name, mate_param_name),
    FOREIGN KEY (mat_name) REFERENCES Mate(name)
        ON UPDATE CASCADE
        ON DELETE CASCADE,
    FOREIGN KEY (mate_param_name) REFERENCES MateParam(name)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);

CREATE INDEX idx_matvalue_param ON MatValue(mate_param_name);
```

**示例数据**

```sql
-- Q235钢的参数
INSERT INTO MatValue VALUES ('Q235', 'youngs_modulus', 210e9);
INSERT INTO MatValue VALUES ('Q235', 'poisson_ratio', 0.3);
INSERT INTO MatValue VALUES ('Q235', 'density', 7850);
INSERT INTO MatValue VALUES ('Q235', 'yield_stress', 235e6);

-- 6061铝合金的参数
INSERT INTO MatValue VALUES ('aluminum_6061', 'youngs_modulus', 68.9e9);
INSERT INTO MatValue VALUES ('aluminum_6061', 'poisson_ratio', 0.33);
INSERT INTO MatValue VALUES ('aluminum_6061', 'density', 2700);
```

### 4.1 级联操作规则

| 父表        | 子表          | ON UPDATE | ON DELETE | 说明                     |

| PhysicsType | MateType      | CASCADE   | RESTRICT  | 禁止删除已使用的物理类型 |
| MateType    | MateTypeParam | CASCADE   | CASCADE   |                          |
